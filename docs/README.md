# Screenshots

Drop app screenshots here and they'll render in the main README.

Suggested shots (dark theme, a topic with JSON messages open):
- `screenshot.png` — main 3-pane view (connections | messages | topics)
- `detail.png` — message detail with JSON syntax highlighting
- `search.png` — search panel with filters

To capture on macOS: `Cmd+Shift+4` then drag over the window,
or `Cmd+Shift+5` for a window/region capture.
